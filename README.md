# Umbra Nera — ChatGPT Work Pet

Complete source and QA archive for the custom animated **Umbra Nera** pet.

## Character specification

- Bayonetta 1-inspired tall sculptural hairstyle
- Bayonetta 2-inspired midnight-blue ceremonial costume and four pistols
- Slim chibi proportions, glasses, mature face, and beauty mark
- Dedicated waiting-for-command pose
- ChatGPT Work Pets v2 atlas with 73 required frames and 16 look directions

## Repository structure

- `pet/` — generation briefs, references, decoded strips, extracted frames, final atlases, and QA reports
- `outputs/` — final distributable sprite sheet and overview images

The final sprite sheet is `outputs/umbra-nera-spritesheet.webp` (`1536×2288`, WebP with alpha, sprite schema v2).

## Validation

The final atlas passed the structural Pets validator and the independent blind direction review. Detailed reports are stored under `pet/qa/` and `pet/final/`.
